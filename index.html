01 / GET STARTED

Installation.

Get the plugin running and make the pack reachable to players.

01

Install the plugin

Put AvenoxTab-1.0.0.jar in your server's plugins/ folder. Start Paper or Spigot 1.21.4 using Java 21.

02

Set a public pack URL

Open plugins/AvenoxTab/config.yml and set pack.public-url to an address every player's computer can reach.

03

Allow pack downloads

For the built-in HTTP host, open TCP port 8123. This is separate from the Minecraft server port.

04

Reload and join

Run /atab reload, join the server, and accept the resource pack. The plugin also offers the pack on player connection.

02 / FIRST RESULT

Quick start.

Display your first image in the tab header.

1

Add a PNG

Place logo.png in plugins/AvenoxTab/textures/.

2

Reference it

Add 'text:logo' to tab.header in your config.

3

Build and connect

Run /atab reload. Accept the pack when you join.

✦

Texture names come from lowercase PNG filenames. For example, logo.png becomes logo.

03 / CONFIGURE

Configuration.

The main settings live in plugins/AvenoxTab/config.yml. Minecraft color codes use &.

config.ymlYAML
tab:
  enabled: true
  header:
    - 'text:logo'
    - '&7Welcome &f{player}'
  footer:
    - '&e{online}&7/&e{max_players} players'
scoreboard:
  enabled: true
  title: '&6&lAVENOX'
pack:
  enabled: true
  auto-refresh: true
  public-url: 'http://play.example.com:8123/pack.zip'
  http:
    enabled: true
    port: 8123
chat:
  icon-enabled: true
Tab list

Set header and footer lines with text and textures.

Scoreboard

Enable the sidebar and choose its title.

Resource pack

Generate the pack and set a public download URL.

Chat

Enable the built-in icon with chat.icon-enabled.

05 / CUSTOM ASSETS

Textures & sizing.

Drop PNG files into plugins/AvenoxTab/textures/. PNG and config changes are checked every five seconds when auto refresh is enabled.

AUTOMATIC FITtext:logo

Fits the image to its position without stretching it.

CUSTOM HEIGHT:text:logo:size=16

Requests a height from 1 to 32 pixels; width stays within 96 pixels.

LEGACY SYNTAX{texture:logo}

The original texture placeholder still works.

▧

Image limits

  • Standalone tab header image: up to 24 × 96 pixels
  • Inline text and scoreboard: up to 8 × 32 pixels
  • Source PNG: above 256 × 256, images are resized in the pack; originals stay intact
✦

chat.png and command.png are installed on first start. Replace them with your own PNGs if you want.

06 / DELIVERY

Pack hosting.

Players must download the generated resource pack before custom glyphs appear.

BUILT IN

HTTP host

Keep pack.http.enabled: true and set pack.public-url to your public server address on port 8123. New packs are served when built.

Best for a simple setup ↗
EXTERNAL

Your web host

Upload plugins/AvenoxTab/pack.zip after every rebuild, then set pack.public-url to its public URL. The plugin does not upload automatically.

You manage each upload ↗
Public URL checklist

Use a URL reachable outside your network. Do not use localhost for remote players. If you use HTTPS, verify the certificate.

07 / REFERENCE

Commands.

Use /atab or /avenoxtab. Admin commands require avenoxtab.admin, granted to operators by default.

COMMANDWHAT IT DOES
/atab reloadReload config, rebuild the pack, and restart the HTTP host.
/atab buildRebuild the pack from current textures.
/atab pack add [player]Offer the pack to a player.
/atab pack remove [player]Remove the pack from a player.
/atab send [player]Alias for pack add.
/atab statusShow texture count, HTTP status, URL validity, and pack SHA-1.
08 / SUPPORT

Troubleshooting.

Work through these checks when an image or pack does not behave as expected.

I see a square instead of an image +

The font glyph did not load. Confirm the pack was accepted, the URL downloads the latest ZIP, and the client runs Minecraft 1.21.4. Use /atab status to inspect the pack SHA-1.

My image does not update +

With built-in hosting, allow up to five seconds, then reconnect if necessary. Restart after changing the plugin JAR. With external hosting, upload the rebuilt pack.zip.

Players cannot download the pack +

Open the public URL from another network. Check TCP port 8123 for built-in hosting, and verify your HTTPS certificate. A localhost URL works only on the server machine.

Where should I check first? +

Run /atab status, then verify the public URL, pack acceptance, PNG filename, and texture reference in config.yml.
